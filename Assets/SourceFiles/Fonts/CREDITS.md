# Font credits (F109 world signs)

All fonts were downloaded from https://github.com/google/fonts (raw files) and are used for the in-world sign lettering. The licence text of each
family sits next to its font file. The static TMP font assets (`* SDF.asset`) are generated from these files by
`LIGHTS OUT > Build > World Signs (restyle missing)` (`WorldSignBuilder.EnsureFonts`).

| Family | Used for | File | Licence |
|---|---|---|---|
| Barlow Condensed SemiBold | hospital signage, name plates, wing plaques | `BarlowCondensed/BarlowCondensed-SemiBold.ttf` | SIL Open Font License 1.1 (`BarlowCondensed/OFL.txt`) |
| Saira Stencil One | stencilled warnings (NO ENTRY, SERVICE UNIT, LOWER LEVEL) | `SairaStencilOne/SairaStencilOne-Regular.ttf` | SIL Open Font License 1.1 (`SairaStencilOne/OFL.txt`) |
| Rock Salt | hand-painted patient warnings | `RockSalt/RockSalt-Regular.ttf` | Apache License 2.0 (`RockSalt/LICENSE.txt`) |
| Reenie Beanie | handwritten notes, tallies, chalk | `ReenieBeanie/ReenieBeanie.ttf` | SIL Open Font License 1.1 (`ReenieBeanie/OFL.txt`) |
| IM Fell English | the shop's engraved and gilt lettering | `IMFellEnglish/IMFeENrm28P.ttf` | SIL Open Font License 1.1 (`IMFellEnglish/OFL.txt`) |
| Cinzel | the shop's name board | `Cinzel/Cinzel-VariableFont_wght.ttf` (default instance, Regular) | SIL Open Font License 1.1 (`Cinzel/OFL.txt`) |

`Inter-Variable.ttf` (UI) and `LiberationSans` (TextMesh Pro default, the fallback of every sign font) are older and keep their own licences.
